\subsection{Penalized Logistic Regression - Combining Extensions}
\label{sup:multiple}

Here we provide examples of constructing LQA-P intervals for the Golub ALL/AML microarray dataset \citep{Golub1999} with three different penalties: lasso, MCP, and SNET with $\alpha = 0.9$. The data comprise 72 diagnostic samples (47 ALL, 25 AML) profiled on Affymetrix HGU6800 arrays, yielding 7,129 gene-expression features per patient. We treat this as a binary classification problem (ALL vs AML). With $p \gg n$ (7,129 vs 72), this is a prototypical high-dimensional setting in which sparsity is desirable for both interpretability and generalization. For each, cross validation was performed to select respective values of $\lam$. For MCP and SCAD, the default values of $\gamma$ were used. The 80\% HDIs for for genes where at least one penalty estimated a non-zero coefficient are provided in Figure~\ref{fig:B1-man3}.
